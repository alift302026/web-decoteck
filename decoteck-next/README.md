# Decoteck Next — Premium Mobile-First WordPress Theme

This is a new theme built separately from the existing decoteck theme. It does not overwrite the current theme or the backup branch.

## Included in this first prototype
- Responsive, animated DECOTECK hero with Persian tagline
- Guided homepage paths: Gallery, Order, Price Calculator, Services
- Mobile navigation with accessible toggle and Escape-key support
- Responsive card layouts and compact legal footer
- Reduced-motion support and lazy reveal effects via IntersectionObserver
- WordPress theme setup and version-based asset caching

## Before activating on a live site
1. Test on a staging copy of WordPress.
2. Confirm actual slugs of Services, Gallery, Calculator, Order, Hardware and Contact pages. Update links if WordPress slugs differ.
3. Replace demo stock photos with optimized, licensed Decoteck project photos.
4. Test all forms, menus, login and dashboard flows. This theme does not replace existing custom page functionality.
5. Test mobile widths, keyboard navigation, PHP/WP debug logs and performance metrics.
6. Confirm current theme and database are backed up before activation.

## Install
Copy the decoteck-next folder into wp-content/themes/ and activate Decoteck Next from WordPress Appearance → Themes on a staging site first.
